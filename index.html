Four structural problems in regulated metadata work

Every clinical dataset must conform to CDISC and eCRF standards before submission. A heuristic audit and workflow shadowing found these bottlenecks in the legacy portal.

Buried navigation

Data models, CRF annotations and terminologies sat under 6+ menu tiers, so researchers memorised folder paths.

Search that missed the data

Lab measurements and value-level metadata weren’t indexed, so biostatisticians exported large Excel files to filter keywords.

Rigid data grids

Fixed-width tables clipped columns and had no sticky headers or pinning, which broke side-by-side comparison on wide monitors.

Compliance risk

Vague validation messages and hidden anonymisation rules sent people to PDF SOPs during time-sensitive audits.

Research that rebuilt navigation around researchers’ mental models

I ran contextual inquiries, heuristic evaluations, open and closed card sorting, and tree testing with 24 clinical data managers and biostatisticians. Decision time fell 40% and first-click success rose from 52% to 94%.

High-density interfaces that keep context

Each workspace uses progressive disclosure, so researchers scan hundreds of variables while checking codelists, anonymisation rules and parent hierarchies in place.

SDTM data table workspace

Multi-column customisation, sticky domain headers and a full-screen focus mode for dual-monitor workstations.

  • Inline codelist badges cut mapping errors by 82%.
  • Anonymisation tooltips replaced PDF manual lookups.
  • One-click GxP-compliant Excel/CSV export keeps active filters.

Operational eCRF dataset

Study builders navigate therapeutic trees, such as Oncology to Breast Cancer, with persistent breadcrumbs and links from CRF questions to SDTM target variables.

  • Two clicks to Catalog Summary and Change Publication audit logs.
  • Inline validation alerts block invalid study configurations.

Global predictive search

One engine for SDTM variables, lab measurements and value-level metadata. Each result shows its parent-folder path and a domain badge.

  • 3.0× faster discovery across multi-study repositories.
  • Faceted domain pills narrow thousands of records with no page reload.

A tokenised design system, handed off to engineering

With front-end leads I built a multi-tier Figma Variables and token library on the Roche R Design System. Shared grid density, focus rings and semantic status tokens lifted build velocity by 40%.

Covers colour tokens, type scale, spacing and data grid, and WCAG 2.2 AA specs.
